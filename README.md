# 橘子集 · 校园闲置演示

静态 HTML/CSS/JavaScript，使用哈希路由和 IndexedDB。运行任何静态 HTTP 服务并打开 dist/index.html。

本项目仅为演示，不含真实登录、支付或共享后端。示例联系方式为虚构；收藏和模拟发布仅保存在当前浏览器。发布前验证交互与布局。

设计方向参考 Monito 的暖色、圆角和响应式商品布局。已在 Figma 复制模板并导入橘子集的可编辑矢量布局与文字：[在线 Figma 设计文件](https://www.figma.com/design/aj8JjrnlIaFq9QbDJWCq7r?node-id=202-697)。导入页面包含八个桌面/手机页面组及组件展示；尚未建立 Figma 原生组件实例、Auto Layout 或交互原型连接。商品照片使用独立的 SVG 内嵌图片图层，兼容导出采用 `xlink:href`。详细来源和本地设计包说明见 [design/README.md](design/README.md)。
