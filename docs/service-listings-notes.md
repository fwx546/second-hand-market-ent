## 步骤 1：数据模型和接口

- 新增 `service` 分类与服务专属参数，实物成色不适用于服务；服务原价和毕业转让标记归零。
- 校验服务方向、计价单位、服务方式、范围、交付周期及预约安排；纯线上无需面交地点。
- 支持服务方向/方式筛选及服务类搜索，沿用原有身份、联系、收藏、图片和编辑权限。
- 新增 Drizzle 迁移与 Cloudflare D1 增量迁移，不修改已应用的历史迁移。
- D1 在事务中保留并恢复商品重建可能级联删除的联系方式、图片关联、收藏、对话和消息；迁移测试逐行比较前后数据。
- 正式库尚未迁移，网页尚未发布。必须先备份、暂停写入并由有 Cloudflare 权限的维护者执行迁移，再合并发布。
