# 服务类改造记录

分支：`feat/service-listings`。每个完成的小步骤单独验证、提交并 push；本分支不触发正式发布。

## 步骤 1：数据模型和接口

- 新增 `service` 分类与服务专属参数，实物成色不适用于服务；服务原价和毕业转让标记归零。
- 校验服务方向、计价单位、服务方式、范围、交付周期及预约安排；纯线上无需面交地点。
- 支持服务方向/方式筛选及服务类搜索，沿用原有身份、联系、收藏、图片和编辑权限。
- 新增 Drizzle 迁移与 Cloudflare D1 增量迁移，不修改已应用的历史迁移。
- D1 在事务中保留并恢复商品重建可能级联删除的联系方式、图片关联、收藏、对话和消息；迁移测试逐行比较前后数据。
- 正式库尚未迁移，网页尚未发布。必须先备份、暂停写入并由有 Cloudflare 权限的维护者执行迁移，再合并发布。

步骤 1 验证：全量 223 项测试、`npm run check` 及增量 schema 校验通过。提交：`85aa096`。

## 步骤 2：动态发布与编辑

- 首页和发布分类加入服务类。选择后切换服务标题、价格单位、服务参数、描述、封面提示及发布按钮。
- 线上服务隐藏地点；线下服务要求地点；自定义单位仅选择后出现。
- 分类切换保留各分类草稿、照片和联系方式；提交剔除不适用字段。
- 新增界面和草稿切换回归测试。全量 225 项测试、`npm run check`、`npm run build:cloudflare` 通过；提交编号见 Git 历史。

## 步骤 3：展示、筛选和接单状态

- 服务详情显示方向、服务方式、计价单位及服务说明，替换成色、线下面交、实物照片和描述文案。
- 服务卡片显示服务方向及方式；不显示购入价和实物成色。
- 桌面和手机提供服务方向/方式筛选；切换分类清理不适用筛选，服务价格排序注明按标价比较。
- 个人中心支持暂停/恢复接单，服务不提供标记售出按钮；四个分类入口适配窄屏。
- 修正“关于”中未反映站内消息功能的旧文案。步骤 2 提交：`2d64807`。
- 验证：全量 226 项测试、源码检查、Cloudflare 构建及完整本地构建通过；浏览器已确认服务分类、纯线上/线下地点、自定义单位和输入保留行为。
